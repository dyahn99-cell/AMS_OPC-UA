# EX600-AMB 두 입력 독립 환산

기존 8011 대시보드의 EX600-W 채널에 적용했다. 별도 채팅의 간이 SQLite 이력 버전 변경은 포함하지 않는다.

- 입력 1(CH0), 입력 2(CH1) 각각 유량/압력 선택, 단위, 부호, 바이트 순서, 원시값·전압·측정값 범위를 저장한다.
- 유량 단위: L/min, m³/h. 압력 단위: MPa, kPa, bar. 선택 단위에 맞는 측정값 하한·상한을 직접 지정해야 하며 단위 선택만으로 기존 범위를 자동 변환하지 않는다.
- 두 값과 독립된 최근 60회 추이를 동시에 표시한다. 한 입력의 범위 초과는 그 입력의 환산값만 보류한다.
- CSV는 두 입력의 measurement_value, measurement_kind, measurement_unit을 각각 기록한다. 이전 flow_L_min 전용 열을 일반 측정값 열로 변경했다. 연결 실패·만료 시 두 입력 모두 결측으로 기록한다.
- 기존 단일 입력 설정은 해당 입력의 유량 설정으로 불러오며 나머지 입력은 환산 미설정을 유지한다.
- CSV는 기존 탭 메모리 기록 방식이다. 이 변경만으로 서버 SQLite 영속 이력이 추가되지는 않는다.

설정: 새로고침 → 해당 EX600-W 채널 → 모듈 위치·입력별 압력/유량 설정 → 두 입력의 실제 센서 범위 지정 → 구성 저장 → 다시 연결.

검증: scripts/check_ex600_module.cjs 통과. 모의 유량/압력 동시 표시, 부호·순서, 음수 압력 범위, 입력별 범위 초과 격리, CSV 종류·단위, 저장 복원, 채널 분리, 모바일 확인. 실제 장비 요청은 모두 차단하여 모의 응답 사용.
