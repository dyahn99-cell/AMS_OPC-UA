# EX600-W / EX600-AMB 채널 통합

기존 채널 구성표에 `EX600-W · 모듈형 (EX600-AMB)`를 추가했다. 기존 Modbus `/read`와 채널 시작 주소 계산을 사용한다. 별도 통신 서버나 별도 유량 페이지를 만들지 않았다.

## 사용 순서

1. 대시보드를 새로고침하고 채널 구성에서 실제 무선 채널에 EX600-W를 선택한다.
2. Configurator에 표시된 EX600-W 전체 입력·출력 할당을 입력한다. 초기 4/4B는 AMB 한 모듈의 최소 템플릿이며 실제 EX600-W 전체 할당을 자동 검출한 값이 아니다.
3. 해당 채널 모니터링에서 AMB의 Unit 번호, 채널 내부 입력·출력 상대 시작 바이트를 입력한다. AMB는 입력 4B, 출력 4B를 점유한다. 앞 모듈과 진단·예약 영역은 상대 위치 및 전체 할당에 반영한다.
4. CH0/CH1 각 2B 수치의 순서·부호 형식을 실제 설정과 대조하고 확인란을 선택한다. 확인 전에는 유량과 수치를 추정 표시하지 않는다. 전체 채널 HEX는 기존 수신 영역에서 확인할 수 있다.
5. PF3A712H가 연결된 CH0 또는 CH1을 선택한다. AMB 원시값 하한·상한, 대응 전압과 유량의 하한·상한을 실제 설정에 맞춰 입력하고 환산 사용을 선택한다.
6. 기존 연결·자동 갱신 버튼으로 읽는다. CSV 기록 시작 후 CSV 다운로드로 파일을 저장한다.

## 동작

- 채널별 구성 저장. 베이스 연결 프로필·무선 채널로 저장 키를 구분한다.
- AMB 위치가 전체 할당을 벗어나면 구성 저장을 거부한다.
- 읽기 응답의 채널·시작 주소·길이를 검사한다.
- 수치 형식은 확인한 16비트 정수 형식만 사용한다. 12bit 분해능을 근거로 0–4095를 자동 가정하지 않는다.
- 확인된 두 점의 선형 환산을 사용한다. 범위 밖 원시값은 보존하고 전압·유량은 보류한다. PF3A의 실제 출력 가변 범위·제로컷 등은 사용자가 설정과 대조해야 한다.
- 모듈 설정 저장은 폴링을 중지하고 이전 진행 중 요청을 무효화한다. 다시 연결해야 새 설정으로 수집한다.
- 입력 실패·만료 시 값과 추이를 비운다. CSV에는 error/stale 등 상태와 빈 수치로 기록하며 0으로 대체하지 않는다.
- CSV에 ISO 시각, 호스트, 무선 채널, 모듈, Unit, 입력 CH, 절대 입력 위치, 상태, 원시값, 전압, 유량, HEX, 바이트 순서·부호·환산 기준을 포함한다.
- 기록은 현재 탭의 메모리에 최대 100,000행을 보관한다. 자동 디스크 기록이나 장기 서버 저장이 아니다. 다운로드 전 탭을 닫으면 기록이 사라질 수 있어 이탈 안내를 제공한다.
- 채널 전환·구성 변경·수집 중지는 기록도 중지한다. 기존 기록은 다운로드할 수 있다.

## 범위와 제한

이번 단계는 EX600-W 채널에 AMB 한 개를 지정하는 구성이다. 여러 종류·여러 개 EX600 모듈을 자동 열거하는 모듈 편집기는 후속 범위다. 현재 전체 할당 입력은 기존 단일 읽기 경로의 한계인 방향당 4–130B, 짝수 바이트로 제한한다. 하드웨어의 전체 지원 범위를 의미하지 않는다.

출력 할당은 다음 채널의 출력 주소 계산에 포함한다. AMB 아날로그 출력 쓰기는 아직 지원하지 않으며 일반 디지털 접점 테스트에 노출하지 않는다. 모듈 진단 비트는 해석하지 않는다.

실제 채널 번호·EX600-W 형번·전체 할당·AMB 오프셋·PF3A 전압 범위·원시값 환산 맵이 확인되지 않았으므로 사용자 저장 구성을 자동 변경하거나 실제 하드웨어 읽기/쓰기를 수행하지 않았다.

## 검증

- `node scripts/check_ex600_module.cjs`: 앞뒤 채널 할당, 모듈 상대 위치, LE/BE·부호, 범위 검사, 환산, 주소 불일치 거부, 실패 시 결측 CSV, 채널 분리·저장 복원, 모바일 검증 통과.
- `node tools/iodd/test_remote_map.cjs`: 기존 채널 할당 검사 통과.
- `node scripts/check_iodd_remote_experience.cjs`: 기존 입력·아날로그·출력 UI 회귀 통과.
- `node scripts/check_iodd_workspace_acceptance.cjs`: 239개 정의 / 432개 레이아웃 및 기존 탐색 회귀 통과.

장비 요청은 모두 모의 응답으로 가로챘다. 테스트의 원시값 0–1000 → 1–5V → 0–12000 L/min은 계산 검사용 임의 기준이며 실제 AMB 사양값으로 제공하지 않는다.
