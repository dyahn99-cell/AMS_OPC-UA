# EXW1 리모트 할당 크기 정리

## 베이스 진단 영역 (입력에만 선행)

- None: 0B
- Simple: 4B
- Advanced: 최대 리모트 설정 15/31/63/127에 따라 10/16/28/52B
- 현재 테스트는 Advanced 15 기준 10B. 전체 시스템 입력/출력 각각1440B.
- 최대 리모트 설정과 실제 등록 개수는 구분한다. 현재 UI CH1–15 제한은 전체 하드웨어 지원 채널 수를 의미하지 않는다.

## 주소 계산 규칙

등록된 채널만 채널 번호 오름차순으로 배치한다. 등록은 유지되고 통신만 끊긴 채널은 할당 영역을 유지한다.

- 채널 입력 시작 바이트 = 베이스 진단 바이트 + 이전 등록 채널 입력 할당 합계
- 채널 출력 시작 바이트 = 이전 등록 채널 출력 할당 합계
- IO-Link 포트 시작 바이트 = 해당 채널 시작 + 고정부2B + 앞 포트 할당 합계
- 실제 디바이스 PD 길이는 디코딩에만 사용한다. 다음 포트 위치는 반드시 할당 길이로 계산한다.
- Modbus 입력 시작 레지스터는2048, 출력 시작 레지스터는0. 바이트 오프셋과16비트 레지스터 주소를 혼동하지 않는다.

예: Advanced15, CH1 RDX2/0, CH2 RDY0/2, CH3 RLA64/64이면 입력 시작은10/12/12B, 출력 시작은0/0/2B. 0B 방향은 영역을 차지하지 않는다.

## 구현 시 확인해야 할 사항

1. 구성표는 등록 여부, 채널, 리모트 모델, 무선 프로토콜, 알림 포함 여부, 입출력 할당을 보유한다.
2. IO-Link 고정부2B를 포함해서 합산한다. 16B씩4포트면 전체66B가 필요하므로 전체64B와 동시에 가정하지 않는다. 실제 Configurator 값을 확인한다.
3. 일부 다른 베이스의 요약 매뉴얼(EXxx-OMA1031)은 RLB 상한130 및 RDM E4 표기가 위 BMTAC 매뉴얼과 다르다. 자동 통합하지 않고 해당 모델 전용 매뉴얼 및 실제 장비 설정과 대조한다. 여기서는 BMTAC 표를 기준으로 사용한다.
4. 모델별 세부 비트 의미, 아날로그 변환, 알림 영역 비트는 각 전용 매뉴얼로 추가 검토한다. 본 문서는 할당 맵 정리이며 UI 구현 완료를 의미하지 않는다.
