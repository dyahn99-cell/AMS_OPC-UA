# IO-Link 포트 중심 화면

- 채널 진입 시 연결 제품을 먼저 표시하는 P1–P4 카드. Class B는 P1/P2만 표시.
- 제품명, 등록된 대표 이미지, IODD 공용 표시 계획의 대표/보조 PD 항목, 사용자가 선택한 설정값 2개 요약.
- 상세 보기와 포트별 설정 페이지로 진입. 마스터 외형은 접힌 상세 정보로 이동.
- 기존 전체 채널 입력 프레임에서 각 포트 할당 바이트를 분리. 다른 포트의 단위/조건이 미확인인 수치는 확정하지 않음. 실제 읽지 않은 설정값과 만료 값은 미조회/만료로 표시.
- 제품/레이아웃/바이트 순서/할당 변경 시 기존 요약 캐시 제거. 설정 변경 알림에도 캐시 제거.
- 설정값은 현재 세션의 상세 화면에서 선택·조회한 값이며, 전체 포트 ISDU를 일괄 자동 조회하는 기능은 아직 아님.

검증: check_iodd_workspace_acceptance.cjs (239 정의/432 레이아웃, P1/P2 값 분리, 설정 페이지 대상, 모바일) 및 check_iodd_product_models.cjs 통과. 모든 장치 요청은 모의 응답 또는 차단; 실제 장비 출력 쓰기 없음.
