# 매뉴얼 기반 위젯 검토 — 2026-09-29

제공된 ZIP의 41개 패키지, 215개 제품 식별자, 239개 IODD 정의를 대상으로 검토했다.
제품군별 대시보드 관련 매뉴얼 페이지와 미해결 사항은 FULL_PRODUCT_REVIEW.md에 기록했다.
모든 비주기 파라미터의 상호 제약과 명령 실행을 검증한 상태는 아니다.

## 적용 결과

- 정확한 IODD SHA와 항목 ID에 결합한 변환 규칙 326개, 적용 정의 129개.
- PD 압력·유량·온습도·누적값 및 일부 압력 제품의 비주기 최대/최소값을 포함한다.
- 매뉴얼 계수와 IODD 표시 정의의 계수·오프셋을 교차 확인했다.
- ISE70/ISE70G/ISE71의 일부 단위에서 4개 계수 불일치를 발견했다. engineering-conflicts.json에 근거를 보존하고 해당 변환은 제외했다.
- 37개 공식 PDF를 로컬 보관하고 SHA-256을 기록했다. X101 사양서는 공식 웹 원문을 근거로 사용했으며 로컬 PDF 해시가 없다.

## 화면 동작

초기 상태는 raw이며, V_Unit 수동 구성 확인 후 수치·게이지·추이가 함께 같은 단위로 바뀐다.
음의 계수인 진공압 게이지는 변환 후 최솟값/최댓값을 정렬한다.
비주기 값은 독립된 Index/Subindex를 사용하고 PD 비트 주소를 재사용하지 않는다.
Boolean 상태와 선택 메뉴는 IODD의 Enable/Disable 등 실제 레이블을 사용한다.
미수신·범위 밖·특수 코드는 정상 측정값으로 표시하지 않는다.

## 미해결 항목

PF2MC 계수 표의 범위 표기, EX260-PIL의 Device ID/압력 지원 설명, PSH 화씨 오프셋 등
상충된 문서는 추정해서 확정하지 않았다. PF2M-X731, IN502-46, 구형 PSH 등은
해당 버전 근거가 더 필요하다. 상세 목록은 전체 검토 보고서와 제품 선택 화면에 있다.
복합 레코드/배열, 표준 변수 참조, 동적 스케일, 진단에 따른 값 유효성,
상호 제약과 쓰기 명령은 범용 원시값 위젯만으로 완료되지 않는다.

## 검증 범위

11,217개 항목의 29,260개 위젯 표시 조합에 대해 모의 DOM 검증을 수행했다.
수식 예제, 경계·특수값·단위 불일치, 음수 게이지와 추이 전환, 제품/버전 누락,
PDF 해시와 변환 근거 연결을 검사한다. 실물 통신·쓰기·패킷 디코더는 연결하지 않았다.
브라우저 보안 정책이 로컬 HTML 열기를 차단하여 화면 육안 검증은 미완료다.

최종 검사: IODD 파서/분류 단위 테스트 5개, Node 위젯/수식/전체 마운트/근거 무결성 검사 4종 통과. JavaScript 문법과 git diff 공백 검사 통과. 앱 전체 check_offline.py는 bundled Python에 fastapi가 없어 테스트 실행 전 중단되었으며 통과로 집계하지 않는다. 해당 실행의 원본 파일 무결성 검사는 변경 없음으로 종료했다.
