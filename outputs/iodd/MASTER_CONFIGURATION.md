# EXW1-RL 수동 구성 — 2026-09-29

전체 위젯 HTML 상단에서 한 마스터의 베이스 ID/채널, 정확한 모델, 무선 프로토콜,
총 입출력 바이트, P1–P4 사용/모드/길이/바이트 순서, 제품 SHA/레이아웃을 설정한다.
저장은 이 브라우저의 localStorage에 수행하며 장비나 기존 운영 설정을 변경하지 않는다.
같은 화면을 다시 열 때 검증한 구성을 복원한다. JSON 텍스트 내보내기/가져오기를 지원한다.
잘못된 가져오기는 현재 편집 내용을 교체하지 않는다. 저장은 검증 통과 시에만 허용한다.
현재 브라우저 저장 슬롯은 한 마스터 구성이며, 다른 구성을 저장하면 해당 슬롯을 대체한다.
여러 마스터의 영구 저장소와 운영 토폴로지 연결은 후속 작업이다.

## 매뉴얼 근거

SMC OM_EXW1-RL_DOC1046608EN-4.pdf, PDF 24,44,155–162쪽.
https://static.smc.eu/binaries/content/assets/smc_global/product-documentation/operation-manuals/en/om_exw1-rl_doc1046608en-4.pdf

- RLAPA8C: 최대 4포트. P3/P4 분기 배선 확인 필요.
- RLBPA7C: IO-Link 2포트. P3/P4 사용은 차단.
- V2.0: 포트별 방향당 0–32 bytes. 총 입출력 각각 A형 2–130, B형 2–66 bytes.
- V1.0: 총 입출력 각각 16 bytes 고정, 포트별 0–14 bytes.
- 입력/출력 각각 2-byte 고정 영역 후 IO-Link 포트만 P1부터 순서대로 배치한다.
- DI/DO/미사용은 가변 PD 영역을 점유하지 않는다.
- 전체 예약 크기는 필요한 합계보다 클 수 있다. IODD 요구량보다 작은 할당은 거부한다.
- 주소는 이 마스터 내부의 상대 바이트 오프셋이다. Modbus 레지스터 주소가 아니다.

PDF 44쪽의 V1.0 범위 텍스트는 0–16으로 적혀 있으나 동일 표의 0x0E,
PDF 24,158–159쪽의 범위와 총 14-byte PD 공간을 근거로 0–14를 적용했다.

## 위젯 연결

포트 위젯 열기는 정확한 SHA와 레이아웃으로 기존 공용 위젯 화면을 연다.
값은 미수신으로 시작하며 모의 샘플 버튼을 누르기 전 실제 수신을 주장하지 않는다.
포트 선택은 현재 화면의 컨텍스트이며, 수집/캐시/장비 쓰기 기능은 없다.
PD Byte Swap은 구성에 보존하지만 패킷 디코딩에는 적용하지 않는다.
배선 확인, 모델 및 프로토콜 선택은 사용자 지정 계획이며 실물 검출 결과가 아니다.
