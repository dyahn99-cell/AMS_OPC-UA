# 商品 UI 체험 기준 — 2026-10-14

기준: 기능을 나열하는 점검 화면이 아니라, 처음 사용하는 사람이 연결 제품을 알아보고 측정 확인과 설정 수정으로 이어지는 경험을 제공한다.

이번 구현
- 채널 요약: 선택 채널·리모트 외형·수동 제품 지정 수·최근 PD 수신 상태·할당 크기를 분리.
- 채널의 연결/자동 갱신 조작과 포트 할당 설정 진입을 같은 요약 영역에 배치.
- P1~P4 바로가기는 물리 순서로 유지. Class B는 실제 사용 가능한 2개 포트만 표시.
- 지정한 제품을 먼저 보여주고, 이미지/핵심 PD/주요 설정값/상세 및 수정 액션을 한 카드에 구성.
- 제품 하나는 큰 카드, 복수 제품은 비교 가능한 카드. 미지정 포트는 압축된 구성 카드.
- 미수신 상태는 값 대신 대시와 연결 후 표시 안내. 미수신값을 만들어 채우지 않음.
- 모바일에도 포트·할당 설정 진입 제공.
- 제품 상세의 이미지와 주 측정 패널을 같은 스타일로 정리.

검증
- 239개 정의 / 432개 레이아웃 워크스페이스 검증.
- 제품 1~4개 지정, 미지정 포트 압축, Class B 2포트, 포트 바로가기와 설정 진입, 모바일 넘침 없음.
- 실제 값 변경/같은 값/모션 줄이기 검증.
- 전체 시스템 묶음/Modbus 설정 진입 검증.
- 장비 호출은 차단 또는 모의 응답 사용. 실제 장비 읽기/쓰기 검증은 하지 않음.

범위: 상품 경험의 첫 기준으로 IO-Link 채널과 제품 상세 진입을 재구성. 모든 제품군과 운영 화면 전체가 상품 출시 수준에 도달했다는 판정은 아님.
