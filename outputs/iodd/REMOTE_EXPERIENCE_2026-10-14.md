# 리모트 종류별 운영 화면 · 2026-10-14

## 반영

- 공통 요약: 입출력 할당, 각 방향 시작 바이트, 접점/채널 수, 실제 수신 기반 ON 개수 또는 조회 상태.
- 디지털 입력: 8비트 바이트별 그룹, IN 번호와 B/bit 주소, ON 윤곽선, OFF와 미확인 구분. 16점 입력 및 8점 입출력 프로필을 따름. 추가 알림 바이트는 별도 원시 영역.
- 아날로그 입력: 4채널 카드, 채널당 2바이트 원시 HEX와 주소. 전압/전류 변환은 전용 맵 검증 전 적용하지 않음.
- 출력: 조회 → 조작 허용 → 접점 조작 단계. 조회 전 안내, 조작 허용 전 ON/OFF 버튼 잠금. 기존 쓰기 대상/기대값 확인, 재조회, 순차 테스트 종료 절차 유지.
- 조회 전·채널 변경·읽기 실패·만료된 응답은 입력 ON 강조를 제거하고 미확인 표시. 같은 채널 갱신은 DOM 카드를 재사용.
- IO-Link 제품 포트 카드와 공용 설정 위젯은 유지. 이미지가 없는 제품에 임의의 외형을 붙이지 않음.

## 검증

- check_iodd_remote_experience.cjs: 최초 미확인, 16점/8점 그룹, 주소, 추가 알림, 수신·오류·만료 처리, DOM 재사용, 아날로그 원시 카드, 채널 분리, 출력 조회/허용 단계, 모바일 통과.
- check_iodd_workspace_acceptance.cjs: 239개 정의/432개 레이아웃, 전체·채널·제품·출력 이동, 설정, 3종 신호 색상, 모바일 통과.
- check_iodd_operational_ui.cjs: 단위, 대표 지표 저장, 통신 실패 시 그래프 제거, 화면 이동, 모바일 통과.
- check_iodd_motion.cjs: 값 변화 강조, 동일 값 갱신 무점멸, reduced-motion 통과.
- 모든 장비 통신은 모의 응답. 실제 장비 요청과 출력 쓰기는 수행하지 않음.

## 남은 확인

아날로그 전압/전류 모드 및 공학 단위 변환, 리모트 전용 설정 맵, 실제 하드웨어로 종류별 읽기/출력 시험. 제품 이미지는 제공되는 CAD 파일과 정확한 모델을 연결해야 함.
