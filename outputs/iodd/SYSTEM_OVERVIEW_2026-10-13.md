# 전체 시스템 화면

## 구현
- 연결 구성: PC → Modbus TCP → EXW1 베이스 → 실제 등록 채널 → IO-Link 포트 제품.
- Modbus 연결 카드를 누르면 대시보드 접속 IP/포트/Unit ID/제한시간/갱신 간격 편집. 장비 Ethernet 설정 변경 기능은 아님.
- 저장된 설정 연결 테스트는 입력 레지스터 1워드 읽기로 응답을 확인하며 출력 쓰기는 하지 않음.
- 베이스 클릭은 기존 등록·할당 구성으로, 채널은 리모트 상세로, 포트는 디바이스 상세로 이동.
- 설비 현황: 서로 다른 채널과 IO-Link 포트를 사용자가 지정한 설비 이름으로 묶음. 연결 대상별 브라우저 저장. 같은 제품 정의와 수신 데이터를 사용.
- 등록 제품과 실제 수신을 구분. 전체 채널을 자동 순회 조회하지 않음. 핵심 PD/선택 설정값은 현재 세션의 확인된 수신만 표시.
- 요약 값 갱신은 텍스트만 갱신해 카드 재생성과 포커스 유실 방지.
- 공유 통신 설정은 PD/ISDU/수동 출력에 동일 적용. 출력 테스트 중 변경 거부, 대상 변경 시 세션 갱신 및 이전 쓰기 요청 거부.

## PF3A CAD
첨부 PF3A701H-L3(0).stp를 로컬 OpenCascade import로 테셀레이션하여 GLB 생성. 선은 테셀레이션의 특징 모서리로 유도한 것이며 원본 BRep 곡선 데이터를 그대로 내보낸 것은 아님. PF3A701H-xx-L3x-xxx 두 IODD 버전에 대표 외형으로 연결. L4/Lx 및 다른 제품에 무조건 매칭하지 않음. 원본 STEP, GLB 및 출처/해시 manifest 유지. 색상은 중립 선화이며 실제 제품 색상을 추정하지 않음.
변환 도구: [occt-import-js](https://github.com/kovacsv/occt-import-js).

## 검증
- check_iodd_system.cjs: 연결/설비 전환, 묶음 저장·재진입, PF3A 3D, 통신 설정 UI, 모바일. 장치/저장 POST 모의 응답.
- check_iodd_workspace_acceptance.cjs: 239 정의/432 레이아웃, 포트 요약·설정·입력/출력·모바일.
- check_iodd_live_functions.cjs: 단위/원시값/포트 분리/출력 조작/테스트 중지·잠금 (모의).
- check_iodd_product_models.cjs: 기존 3D·마커·카메라·채널 분리 유지.
- Python 출력/HTTP 26개, 연결 설정 3개 검증 통과.
실제 장비 통신/출력은 이 작업에서 검증하거나 실행하지 않음.
