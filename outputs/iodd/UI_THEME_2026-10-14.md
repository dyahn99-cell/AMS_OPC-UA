# 전체 페이지 테마 정리 · 2026-10-14

- 대상: 전체 시스템, 채널·포트, 모니터링, 출력, 구성·점검, Modbus·그룹 설정 창, 별도 디바이스 설정 페이지.
- 공통 기준: SMC 블루 #006bb6, 네이비 #0b2d51, 흰색 패널, 회색 보조 텍스트. 선택·주요 버튼·핀 표시는 블루. 실제 수신·ON은 녹색, 경고는 황색, 오류는 적색, 미확인·미수신은 중립색.
- 기존 CSS의 장식용 녹색 193곳을 수정했다. 남은 녹색 선언 23곳은 수신·ON 상태용이다. CAD 제품 선화는 유지했다.
- 설정 화면: SMC 헤더, 제목·닫기, 조회·적용 영역, 검색·필터, 표시 선택 요약, 상태 메시지, 도움말, 범위·선택지가 있는 표. 읽기 전 쓰기 잠금, 범위 검사, 순차 전송·재조회, 실패 시 중단은 유지했다.
- 밝은 대표 지표 카드에 남은 옅은 글자와 어두운 선택 입력을 수정했다. 차트 첫 계열은 블루로 맞췄다.

## 검증

- check_iodd_workspace_acceptance.cjs: 239개 정의, 432개 레이아웃, 페이지 이동, 디지털·아날로그·출력, 3종 신호 색상, 모바일 통과.
- check_iodd_user_settings.cjs: 13,288개 설정 바인딩, 포트 분리, 표시 선택 저장·동기화, 범위 오류 차단, 2개 순차 쓰기·재조회 확인 통과.
- check_iodd_system.cjs: 전체 구성, 그룹 저장, 포트 이동, Modbus 설정 창 테스트·저장, 모바일 통과.
- check_iodd_product_experience.cjs: 제품 1~4개, 미지정 포트, Class B 2포트, 모바일 할당 진입 통과.
- 설정 페이지 1500px / 390px: 가로 넘침 없음. 로고 정상 로딩, 적용 버튼 공통 블루 확인.
- 실제 장비 요청·출력 쓰기는 수행하지 않았다. 장비 관련 테스트는 모의 응답을 사용했다.
