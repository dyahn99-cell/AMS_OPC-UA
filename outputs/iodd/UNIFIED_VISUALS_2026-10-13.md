# 제품 선화와 가독성 정리 — 2026-10-13

- 3D가 확보된 EXW1-BMTAC / EXW1-RLAPA8C / PFUW760-L1 / PF3A701H-L30에 공통 선 색상과 제품 크기 대비 굵기 적용.
- 공통 구현: tools/iodd/outline_geometry.py. CAD 단위에 상관없이 외곽선과 내부선 비율 동일.
- 원본 CAD 표면·조립 변환은 유지. 곡면 외곽은 확장된 역방향 표면으로 표현하며, 내부선은 실제 CAD feature 경로를 사용. 기존 view-dependent silhouette 선의 중복 제거.
- 모든 제품 포스터를 같은 시점, 흰 배경, 500×400 CSS 크기 / 2배 해상도로 다시 렌더링.
- 3D 회전·표현 옵션은 펼침 영역으로 이동. 크게 보기는 바로 접근.
- 포트 카드 제품 이미지 / 제품명 / PD / 주요 설정값 / 상세 및 수정 버튼을 구분. 데스크톱 4개 포트, 중간 화면 2열, 모바일 1열.
- 낮은 대비의 설명 문구 개선, 중복된 포트 화면 제목 제거.
- 3D가 없는 제품에 새 형상을 만들어 넣지 않았음. 공식 도면과 제품 미등록 표현은 남아 있음.

검증: CAD 4종 로딩 및 반대 시점 렌더링; 제품 모델 UI 검증; 전체 시스템 화면 검증; 239개 정의 / 432개 레이아웃과 모바일 수평 넘침 포함 워크스페이스 검증 통과. 장비 요청은 차단 또는 모의 응답 사용.

전체 운영 UX를 완성한 변경은 아님. 이번 변경 범위는 공통 제품 외형 표현, 표시 대비, 포트 카드와 외형 조작 동선.

추가 조정: 작은 썸네일의 흐릿함을 줄이기 위해 내부선 반경 비율 0.0024, 외곽선 비율 0.0040 및 짙은 네이비 선 적용. 선택·주요 버튼·통신 경로는 블루 계열로 변경. 상태용 그린 / 오렌지 / 레드 유지. CAD 4종 렌더 및 전체 워크스페이스·모바일 검증 재통과.
