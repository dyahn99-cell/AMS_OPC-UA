# 전체 IODD 공용 위젯 — 구현 범위

## 결과

- 장비 식별 항목 215개, IODD 정의 239개, 분석 항목 11,217개.
- 제공된 manifest의 모든 제품군을 선택할 수 있으며 제품군·모델·제품 ID·Device ID로 검색한다.
- 여러 IODD 정의가 있는 제품은 버전을 명시 선택해야 위젯을 연다.
- PD IN, PD OUT, ACYCLIC을 구분하고 조건부 PD의 Layout과 조건을 보존한다.
- 표준 변수 참조는 별도 미해석 목록에 표시한다. 이를 해석된 11,217개 항목에 포함하지 않는다.

## 공용 위젯

| 유형 | 동작 |
|---|---|
| 수치 | raw 숫자, 범위 및 특수 코드 처리. 확인된 규칙은 수동 단위 확인 후 변환 |
| 게이지 | IODD 첫 숫자 범위 기반 게이지. 확인된 규칙은 수치와 동일 단위로 전환. 음수 계수 처리 |
| 추이 | 사용자가 추가한 최대 30개 모의 샘플. 실제 장비 이력 아님 |
| 누적 표시 | 전달받은 값을 그대로 표시. 누적 항목 의미는 별도 확인 필요 |
| 상태 | boolean 또는 IODD 선택값의 상태명 |
| 문자 정보 | 문자열·옥텟 원문 표시. 옥텟 디코딩 미구현 |
| 수치 파라미터 | 원시 입력값 미리보기. 실물 쓰기 비활성 |
| 선택 파라미터 | IODD 선택값 목록. 실물 쓰기 비활성 |
| 복합 항목 | 레코드 하위 정의와 배열 정의 확인. 값 디코딩 미구현 |
| 미해석 정의 | 알 수 없는 자료형의 정의 보존 및 표시 |

위젯은 `assets/iodd-widgets.js`의 공용 렌더러를 사용한다.
제품별 전용 HTML이나 통신 요청을 생성하지 않는다. mount에는 제품 정의와
샘플을 전달하며, 반환된 setSample으로 값을 갱신한다. transport binding은 별도다.

## 재생성 및 검증

`python tools/iodd/build_all_widgets.py`

`node scripts/check_iodd_widgets.cjs`

`node scripts/check_all_iodd_widgets.cjs`

전체 11,217개 항목 × 지원 표시 방식 29,260개 DOM 모의 마운트 통과.
미수신/잘못된 샘플/논리값/자료형 범위/정밀 정수 처리 검사 통과.
독립 HTML JSON 읽기와 JavaScript 구문 검사 통과.
브라우저 시각 검증은 별도로 필요하다.

## 경계

모든 제품에 표시 가능한 위젯을 제공한 단계이며, 모든 장비의 실물 지원을
검증했다는 의미는 아니다. 단위·배율·조건 선택 평가, 표준 IODD 정의 결합,
EXW1 포트 매핑, ACYCLIC 요청 큐, 실제 이력·쓰기는 아직 연결되지 않았다.
구동·밸브·이오나이저도 정의된 항목의 자료형별 위젯을 공유한다.
전용 모터 조그, 출력 구동 등의 실물 제어 화면은 검증 없이 활성화하지 않는다.

## 전체 제품 매뉴얼 반영

41개 패키지의 검토 근거·미해결 사항을 제품 선택 화면에 표시한다. 129개 정의/326개 변환 규칙을 적용했고 4개 계수 충돌은 제외했다. 상세 범위와 검증 제한은 MANUAL_REVIEW.md와 FULL_PRODUCT_REVIEW.md를 따른다.
