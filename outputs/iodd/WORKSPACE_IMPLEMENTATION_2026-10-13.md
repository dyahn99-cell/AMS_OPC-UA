# 워크스페이스 구현 완료 기록 — 2026-10-13

요청한 다섯 가지 구조 정리를 로컬 대시보드에 적용했습니다.

1. 전체 현황 / 리모트·포트 / 디바이스 상세 분리
   - 루트 URL은 전체 현황, 제품 정의가 포함된 링크는 디바이스 상세로 시작합니다.
   - IO-Link 채널 선택 → 리모트·포트 → 논리 포트 선택 → 해당 디바이스 상세로 이동합니다.
   - 디지털/아날로그 입력은 입력 현황, 출력 전용 리모트는 출력 접점 화면으로 이동합니다.
2. 디바이스 상세의 정보 우선순위
   - 대표 측정값+추이 → 보조 측정값 → 사용자 선택 설정 → 접힌 상태·진단.
   - 디바이스 상세에는 제품 외형만 표시합니다. 리모트 외형과 포트 상태는 별도 화면에 있습니다.
3. 상태 표현
   - 데이터 수신, 데이터 해석/유효성, 제품 상태, 출력 메모리를 구분합니다.
   - 일반 Boolean ON은 녹색, 명명된 오류/알람 신호는 붉은색, 강제 출력/시험 신호는 파란색입니다.
   - 검증되지 않은 시험 미리보기는 점선 표시이며 실제 수신된 정상값으로 취급하지 않습니다.
   - 신호 이름 기반 의미 분류는 표시 후보 규칙이며, 모든 제품의 오류 코드 의미를 검증했다는 뜻은 아닙니다.
4. 설정 및 조작 진입점
   - 설정은 같은 디바이스 설정 페이지에서 항목 선택·읽기·일괄 적용합니다.
   - 본문에는 사용자가 선택한 설정만 표시합니다. 숫자 설정은 검증되지 않은 단위 변환을 적용하지 않습니다.
   - 출력은 기존 대상/예상값 검증과 조작 허용을 유지한 공용 접점 패널을 사용합니다.
5. 공용 위젯 구성 규칙
   - build_presentations.py가 measurement/state/diagnostic/output 역할, signal_kind, display_policy를 생성합니다.
   - IoddPresentation.plan()이 선택 레이아웃의 대표값/보조값/상태/진단/출력/설정을 구성합니다.
   - 동일한 위젯으로 239개 정의, 432개 레이아웃을 검사했습니다. 품번별 별도 화면을 추가하지 않았습니다.

검증:
- check_iodd_workspace_acceptance.cjs: 전체 탐색, 포트별 제품 유지, 선택 설정 표시, 신호 색상 구분, 입력/아날로그/출력 역할, 모바일 통과.
- check_iodd_ui.cjs: 데스크톱·모바일, 구성 접힘, 구성 잠금, 별도 설정 페이지 통과.
- check_iodd_live_functions.cjs: 단위/원시값, P1/P2 분리, 출력 ON/OFF, 순차 테스트 중지와 잠금, CH2 할당 위치 통과.
- check_iodd_user_settings.cjs: 239개 정의의 13288개 읽기 바인딩, 선택 저장, ISDU 읽기, 범위 검사, 일괄 적용·재조회 통과.
- check_iodd_product_models.cjs: 3D 포트 선택/카메라/채널 분리/미등록 외형 처리 통과.
- tools/iodd/test_presentations.py: 4개 검사 통과.

검증은 모의 장비 응답 또는 장비 요청 차단으로 수행했습니다. 실제 장비 출력/설정은 변경하지 않았습니다.
전체 채널의 실시간 온라인 상태를 자동 조회하지 않습니다. 현황의 조회 이력과 실패/만료는 현재 브라우저 세션에서 수행한 조회를 기준으로 합니다.
아날로그 전압·전류 단위 해석, 미보유 제품 외형, 실제 장비 조합 검증은 후속 작업입니다.
